제가 요구사항에 따라 두 개의 파일(`todo_cli.py`와 `test_todo.py`)을 수정 및 작성 완료했습니다.

### 작업 요약
1.  **`workspace/todo_cli.py` 수정:** `main()` 함수 내에 명령어(`command`)의 존재 여부 및 인자(`task_index`)의 논리적 유효성(예: `task_index`가 1 이상인지)을 확인하는 로직을 추가했습니다. 유효하지 않은 입력 시에는 사용자에게 명확한 에러 메시지를 출력하고 프로그램을 종료하도록 수정했습니다.
2.  **`workspace/test_todo.py` 업데이트:**
    *   `test_01_command_missing`: 명령어 자체가 누락된 경우를 테스트합니다.
    *   `test_02_invalid_command`: 존재하지 않는 명령어를 실행했을 때의 예외 처리를 테스트합니다.
    *   `test_04_invalid_index_for_complete`: `complete` 명령어에 유효하지 않은 인덱스(0 등)를 전달했을 때 비즈니스 로직 예외 처리를 테스트합니다.

### 단위 테스트 실행
이제 해당 파일들이 올바르게 작동하는지 검증하겠습니다. `run_shell` 도구를 사용하여 테스트를 실행하겠습니다.

```bash
python3 -m unittest test_todo.py
```

테스트 실행을 진행하겠습니다.
